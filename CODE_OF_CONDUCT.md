# Codigo de conducta

## Nuestro compromiso

Participar en este proyecto debe ser una experiencia libre de acoso para todas las personas,
independientemente de su experiencia, identidad o procedencia.

## Comportamiento esperado

- Respeto y critica constructiva.
- Colaboracion y transparencia.
- Uso etico: este material es para defensa y analisis autorizado.

## Comportamiento inaceptable

- Acoso, insultos o ataques personales.
- Publicar datos personales de terceros.
- Usar el contenido para actividades ilegales o no autorizadas.
- Introducir codigo malicioso.

## Aplicacion

Los mantenedores pueden eliminar aportes y bloquear participantes que incumplan estas normas.

## Alcance

Aplica a issues, pull requests, discusiones y cualquier espacio del proyecto.
